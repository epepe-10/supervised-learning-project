\section{Introduction}
\label{sec:intro}

We predict whether a person earns more than \$50{,}000 a year (\pos) from their
census record: age, education, job, working hours, household situation and
capital income. The data is the Adult dataset, extracted from the 1994 US
census: 48{,}842 people, 14 features and a binary target in which only 23.9\% of
people are positive. The task is therefore a binary classification on tabular
data with an imbalanced target.

The goal is a complete proof of concept, from the raw table to a tuned,
explained and calibrated model evaluated on an untouched test set. The whole
project follows one validation protocol. The data is split once into a
development set (80\%) and a test set (20\%). Every decision (preprocessing,
features, model, hyperparameters, imbalance remedy and decision threshold) is
made with 5-fold stratified cross-validation on the development set only. The
test set is used once, at the very end (Section~\ref{sec:test}).

The report follows the project requirements in order (Sections~\ref{sec:eda}
to~\ref{sec:test}). The fairness and bias audit (requirement 10) was removed
from the scope of the project by the instructor, so it is not covered. The
code, and the order in which to run the scripts, are described in the
repository's \code{README.md}. Supporting figures, tables and equations are in
the appendix.
